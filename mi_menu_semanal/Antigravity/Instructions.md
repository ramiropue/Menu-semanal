# Project Objective

Create an application called **Mi menú semanal** to manage my recipes, plan weekly meals, organize the food I have in my freezers, and create a shopping list, using Next.js (App Router) and Tailwind.

Keep in mind that this is an application that will primarily be used on mobile devices, so it works responsively, with a mobile design in mind.

The project has already been created and Tailwind is installed, but it does not have any styles or functionality yet. The goal is to implement the design and the basic features of a modern, premium, and minimalist recipe and meal-planning app, following exactly the designs shown in the provided references, which are located in the **"Antigravity"** folder inside the project.
